The Bureau Archive

One visual language for the Haunted Ohio website and every game. A paranormal investigation bureau’s digital archive: night ink, aged parchment, gold lettering from the badge, and ember for action. Each game keeps its own personality inside the same system.

01

Color

Night is the default. Daylight is a secondary parchment theme; use the switch at the top right to compare. Every color is a token, so a theme change never touches the components.
