# Performance report: Room 214

Budget as in CONTRACTS.md. Measured by `room214-play.test.mjs` (Chromium, 4x CPU throttle, moving with the light on): **60 fps, 35 live game objects** (limit 400). The three floors are pre-rendered once into textures; per frame the game draws one player, one porter, a handful of items and a flashlight cone (about 30 rays with line-of-sight marching, drawn as one polygon mask). Our code is about 110 KB uncompressed (including the shared files), well under the 450 KB budget, with no image or audio files. Renderer: Phaser CANVAS, `powerPreference: low-power`. Real low-end tablet measurement is still a to-do.
