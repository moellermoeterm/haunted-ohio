# Game guide for course leaders

Four writing games, each played in the browser. Nothing a student types is sent anywhere; work stays in that browser until the student exports it.

## What each game teaches
| Game | What students do | What it teaches |
|---|---|---|
| **The Haunting Files** | Sort a reported haunting into evidence types, find where two witnesses disagree, connect exhibits, defend a theory, then write a field report. | Telling fact from legend, citing evidence, writing a claim you can defend. |
| **The Last Light** | Survive a silent Ohio: tune a radio, pack supplies, decide whether to trust a stranger, and keep a journal. After three missions, write a ten-beat survival story. | Reading for detail, explaining a decision, short and clear messages, building a story from your own notes. |
| **The Veil** | Explore a closed chapel in two worlds, solve what the Keeper's bell meant, write field notes, then an original horror story. | Atmosphere through the senses, clues and foreshadowing, showing instead of telling. |
| **Room 214** | Sneak through a closed hotel, find the room missing from the floor plan, notice details along the way, and write a journal, an account and a story seed. | Sensory detail, separating what you saw from what you guess, suspense without gore. |

Each game opens with three short cards and then small tips that point at what to do next. The **?** button in each game lists one-line tips and can replay any tip.

## How cases are assigned
- Each game has six cases (or scenarios). A student's case is picked at random the first time they start on a device, and it stays the same on that device.
- Students never choose a case and never see its number, so neighbours may or may not have the same case.
- Starting over keeps the same case. Only "Erase my progress" in the game's settings clears it, and then the next start picks again at random.

## Previewing a case as a leader
Add `?preview=N` to a game's address, where N is 1 to 6. For example, open The Veil and add `?preview=3` to the end of the address.
- A yellow banner says it is a leader preview.
- A preview is a throwaway copy. It never changes a student's game or assigned case on that device.
- The leader tools page (password required) has all six preview links for each game.

## Exporting a student's save
Saves live in the browser on the device. To move a game to another device, or to keep a copy:
- **The Haunting Files** and **The Last Light:** open the menu, choose **Save and settings**, then **Export save file**. On the other device, use **Import save file** on the same screen.
- **The Veil** and **Room 214:** press **Saves** in the top bar, then **Export**. Use **Import** on the other device.
- Writing can also be downloaded as a text file from inside each game (the journal, the report or the story).

Clearing the browser's data erases saves that were not exported.

## Settings that help on weak devices or for comfort
- **Low effects** turns off moving light and flicker. The Last Light also has **Text mode**, which plays the radio mission as a page with no animation.
- **Sound** is never needed: every sound shows a caption. Volume and mute are in each game's settings.
